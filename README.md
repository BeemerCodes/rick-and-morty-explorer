
# Rick and Morty Explorer

Projeto acadêmico desenvolvido para a disciplina Web Programming For Front-End.

## Sobre o projeto

O Rick and Morty Explorer é um site que apresenta personagens da série Rick and Morty utilizando dados de uma API pública.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## API utilizada

Rick and Morty API:
https://rickandmortyapi.com/

## Funcionalidades

- Exibição dos personagens.
- Imagens e informações dos personagens.
- Carregamento dinâmico dos cards.
- Botão para carregar mais personagens.
- Layout responsivo.
